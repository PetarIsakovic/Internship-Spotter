# Internship-Spotter

**Rejection or Offer?** — a fast browser game where you sort a flood of recruiting
emails from the companies that haunt every UWaterloo co-op cycle (Jane Street,
Citadel, Two Sigma, Stripe, Shopify, Google, OpenAI, and more). Read each email and
decide: is it a **rejection** or a real **offer** — before the timer runs out.

## Play

Open `index.html` in any browser, or jump straight into `game2-rejection-or-offer.html`.
No install, no build, no server.

## Features

- **50+ emails** across ~37 real tech/finance companies, including tricky soft-rejections
- Single fixed difficulty — no menus, just play
- Streaks with a **combo multiplier** and a speed bonus for fast calls
- **Levels** that speed the inbox up as you go
- **Phrase highlighting** — after each guess, the tell-tale phrase is highlighted so
  you learn exactly what gave it away
- Persistent **high score** and **best streak** (saved in your browser)
- End-of-run stats: accuracy, emails sorted, average decision time
- Keyboard controls (`←`/`A` = Rejection, `→`/`D` = Offer, `Space` = pause) and sound
